# ChemLeap 0.1.1 与 AutumnOS

制作人：派蒙。应用ID cn.labchronicles.chemleap，SDK0.3.0，存档格式1，仅声明saves。商店使用根autumn.store.json；v0.1.1 Release独立包含ChemLeap-0.1.1.autumn、autumn.release.json、SHA256SUMS。包与两层清单须一致，源码ZIP不能安装。

最低内部宿主0.5.1-local.8保留，用于兼容旧版已具备的明确确认开发预览；这是最低包协议兼容要求，不是普通启动安全认证。旧宿主可在设置开启开发者模式、用开发者工具预览下载的包。普通商店发现/下载与应用执行是不同阶段。

AutumnOS 0.5.2-local.1本地候选新增通用来源隔离：固定WebView2 154原生Connection-Allowlist与严格CSP，每实例在宿主nonce挑战形成证明后才执行包，失败关闭，结束/崩溃撤销。该宿主源及EXE不放入本游戏仓库，本次不发布宿主。普通游戏跳跃、保存与新实例读回尚待真实桌面条件允许后测试，不能宣称本游戏0.1.1修复所有旧客户端。

本版本只统一包内版本与发布说明，物质/反应/生成/跳跃等玩法代码保持。安装更新应通过宿主正规流程，在结束现有游戏后进行；声明的存档格式保持1，真实升级矩阵为not_run。浏览器预览使用localStorage，宿主内使用按app/source/account绑定的SDK存档，二者分开。

仓库当前既有Topics保留，不自动添加其他分类或构建认可名单。旧客户端若不识别某个分类标签可能显示未分类/提示分类与展示清单不同；分类不增加权限，也不免除来源、包hash、版本和宿主隔离检查。

模型/材料实际结果及新旧版边界见TESTING.md；0.1.0历史Release保留不改写。
